# Módulos de SergioWilliam2209

Fundação TypeScript provisória para módulos reutilizáveis da aplicação Electron compartilhada. Esta pasta não é uma segunda aplicação Electron e, por enquanto, não contém regras de negócio.

## Desenvolvimento

```bash
npm install
npm run check
npm run build
```

O código-fonte fica em `src/` e a compilação em `dist/`. Compras, materiais, cotação e integração CEP serão acrescentados em incrementos próprios após validação dos contratos e da estrutura compartilhada. A configuração poderá ser alinhada à compilação coletiva da Amanda Sousa antes da integração.
